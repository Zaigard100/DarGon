# Пак-пример «Мастерская механика»

`workshop/` — пак из 20 уровней, собранный только из того, что доступно автору пака: префабы игры, свои префабы и текстуры, DGScript. Каждая комната показывает один приём, финал — все сразу. Открывается в редакторе паков («Открыть…» → `examples/workshop`), там же можно запустить любой уровень под отладчиком (F6, F9).

Играть: «Экспорт .dgpack…» в редакторе и положить файл в `~/.dargon/packs` (на Android — «Паки» → «Добавить пак»), либо `--pack=examples/workshop` при запуске игры с ПК.

## Что где

| Уровень | Приём |
|---|---|
| 01 Мастерская | таблички, сундук, предметы; первый скрипт — `every()` мигает лампами |
| 02 Ключи и замки | цветные ключи, двери, запертый сундук |
| 03 Кнопки | обработчики `onUse` прямо в уровне (строка и массив строк), `use` в обработчике, ложная стена, достижение из скрипта |
| 04 Нажимные плиты | хук `step(x, y)` через общую шину `lib/events`, плита-ловушка, мост из отложенных `setTile` |
| 05 Часовой механизм | `every()` + `cancel()`: решётка открыта 9 секунд, лампы считают время; шипы |
| 06 Патруль | стражи ходят по рядам (`lib/patrol`, модуль `math`), лечебная зона |
| 07 Огненный ритм | скрипт-«дирижёр» включает и гасит огнемёты; хук `loop(dt)` |
| 08 Тьма | тёмный уровень, контрольная точка, скрытые ловушки, ядовитая зона; светлячок летит по кратчайшему пути |
| 09 Лавка и тайник | лавка, рычаг (свой префаб с событием `use`), тайник с пасхалкой |
| 10 Живые стены | проходы меняются `setTile`; стена не встаёт на героя (`px`, `py` из `lib/events`) |
| 11 Мост под ногами | мост строится под ногами и рушится за спиной; хрупкий пол |
| 12 Карусель телепортов | три телепорта в одной клетке, включён один — по кругу |
| 13 Камикадзе | кристалл открывает выход и клетки; `remove()` |
| 14 Тир | арбалеты и арбалет с наведением, кусты, рычаг обесточивает всё; достижение за проход без рычага |
| 15 Жизнь | «Жизнь» Конвея на клетках карты (`lib/life`), своя легенда карты, кнопки управления |
| 16 Саймон | случайная последовательность (`rand`), показ лампами, ввод плитами, раунды |
| 17 Лабиринт | новый лабиринт при каждом входе (`lib/maze`), таймер на достижение |
| 18 Змей | голова идёт к герою, тело следом, растёт от кристаллов — всё на `moveTo()` |
| 19 Сапёр | мины раскладывает скрипт (с проверкой, что путь есть), цифры — запас объектов `digit`; хук `init` |
| 20 Сердце механизма | финал: фазы арбалеты → стражи по кругу → лава, удары по плитам-зарядам, конец игры |

Общие скрипты — в `workshop/levels/lib/`: `util` (включить, выключить, отложенный вызов с аргументом), `events` (несколько слушателей на хуки уровня и позиция героя), `patrol`, `life`, `maze`.

Свои префабы (`workshop/prefabs/`): решётка, ложная стена, плита, лампа, кристалл, клетка сапёра, страж, змей, сердце механизма, рычаг, лава, украшения. Картинки — в `workshop/textures/`.

В паке есть режимы со стартовыми наборами и 19 достижений всех видов: за уровень, за уровень без урона, счётчики, смерть от лавы и змея, прохождение пака и достижения из скриптов (`achieve`).

## Проверка

`./gradlew check` проверяет пак (`:tools:level-check:checkExamples`) и проходит его целиком ботом: `WorkshopWalkthroughTest` выполняет маршрут `core/src/test/resources/workshop-routes.txt` в настоящем движке и падает, если герой погиб, застрял или скрипт выдал ошибку. После правки уровней поправьте и маршрут.
